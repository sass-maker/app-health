# Portfolio structure directions

These three static previews explore the owner's 2026-09-28 request to make the App Health dashboard easier to scan across all 55 active products, including 13 internal products. They preserve the previously approved Watchtower visual language in `.fleet/design-review.json`.

- [A: Overview with collapsible daily ledger](A-overview-collapsible-ledger.html) keeps request health and a compact daily summary on one page; the 55-row ledger expands when needed.
- [B: Dedicated Daily tab](B-dedicated-daily-tab.html) gives the completed-day report its own navigation destination and separates product activity from environment-level request health. Recommended for the clearest 55-product scan.
- [C: Segmented coverage workspace](C-segmented-coverage-workspace.html) combines product scope, evidence state, and request health in one denser Overview.

Each preview has a desktop and 390px screenshot. Rows, metrics, health states, and events inside the previews are illustrative; only the catalog scope of 55 total and 13 internal products was checked against the current active/primary catalog. Unknown means missing or unqualified evidence, never a measured zero. The owner has not yet selected a structure, and no production navigation or dashboard code has been changed for these directions.
